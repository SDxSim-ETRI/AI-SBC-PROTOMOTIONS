## Project and documents

ProtoMotions3 is a GPU simulation and reinforcement learning framework for humanoids and robots.
This fork hosts AI-SBC hip assistance: HLP predicts future hip angles, LLP produces assist torque,
and a frozen mimic tracker acts as the simulated wearer. Python 3.8+, Apache-2.0.

## Environment and commands

Run commands from the repository root. `sbc` is the ProtoMotions/Newton + online ManiFlow environment;
`maniflow` is for ManiFlow training. This workspace's Python is `/home/bak/miniconda3/envs/sbc/bin/python`.
GPU failures must be diagnosed from current `nvidia-smi` and runtime output, not a past session's access error.

```bash
pip install -e .
pip install -r requirements_<sim>.txt  # isaacgym | isaaclab | newton | genesis | mujoco

# Current W1 + H1 + L1 × 0.5 comparison, existing walk, 40 seconds, headless
python examples/experiments/assist_skeleton/run_system.py

# Show the wearer using its saved robot configuration
python protomotions/inference_agent.py \
    --checkpoint checkpoints/W1_wearer_human/last.ckpt \
    --motion-file data/motion_for_trackers/skeleton_torque_suit_gait.pt \
    --simulator newton --num-envs 1
```

The integration runner defaults to W1, the pinned H1 file, L1, gait motion 0 and wearer calibration.
A different LLP path or an oracle probe defaults to scale 1; explicit `--assist-scale` wins.
Historical evaluations must specify their original options from `meta.json`.
Never pass `--robot-name` to `inference_agent.py`; it loads the checkpoint robot configuration.
Generic training/config examples are in `examples/experiments/format.py` and the framework document.
Newton was tested with 1.0.0; MuJoCo is CPU-only with `num_envs=1` for quick checks.

Training outputs live in ignored `results/<experiment>/`; retained models live in
`checkpoints/<version>/` with `INFO.md` and Git/LFS. Preserve weights, source data and raw evaluation
records during documentation cleanup. Check existing uncommitted changes before editing.

## Architecture — where to look

These files carry the design docs; read the relevant one before changing that area.
- `protomotions/train_agent.py` — config pipeline: `robot_factory()`/`simulator_factory()` → experiment file (`configure_robot_and_simulator`, `env_config`, `agent_config`; signatures in `examples/experiments/format.py`) → CLI `--overrides` → pickled `resolved_configs.pt`. Resume loads the pickle and does **not** re-run the experiment file. Training applies the experiment inference overrides before saving `resolved_configs_inference.pt`. Inference loads that pickle → `apply_backward_compatibility_fixes` → CLI overrides; it does not re-run the experiment file.
- `protomotions/envs/base_env/env.py` — `step()`: action processing → `simulator.step()` (decimated substeps) → state/context update → control components → obs → rewards → terminations → reset.
- `protomotions/envs/mdp_component.py`, `context_views.py`, `component_factories.py` — obs/reward/termination = `MdpComponent(compute_func, dynamic_vars={...: EnvContext.current.dof_pos}, static_params={...})`, managed by `ComponentManager`; `FieldPath` yields a path string at class level and the tensor at instance level.
- `protomotions/simulator/base_simulator/simulator.py`, `simulator_state.py` — abstract `Simulator` + `RobotState`/`StateConversion` (COMMON vs SIMULATOR body/DOF ordering). Common quaternion = xyzw (IsaacGym/IsaacLab convert from wxyz). Control modes `BUILT_IN_PD` / `PROPORTIONAL` / `TORQUE`. Friction combine: PhysX AVERAGE vs Newton MAX (`convert_friction_for_simulator`).
- `protomotions/agents/` — `BaseAgent.fit()` (rollout → advantages → minibatch optimize → periodic eval); PPO ← AMP ← ASE, Mimic/ADD ← AMP; MaskedMimic = distillation. Models are `TensorDictModuleBase` using `nn.LazyLinear` (shapes inferred on first forward).
- `protomotions/robot_configs/` — per-robot assets/control/body mapping; `KinematicInfo` extracted from MJCF in `__post_init__`.
- `protomotions/components/` — `motion_lib.py`, `pose_lib.py`, `scene_lib.py`, `terrains/`.
- `protomotions/utils/simulator_imports.py` — IsaacGym/IsaacLab must be imported before torch.
- `protomotions/assist/` — independent HLP + LLP controller, actor loading and skeleton features. `protomotions/simulator/newton/substep_hook.py` runs assistance inside the wearer step.

## Gotchas

- `resolved_configs*.pt` are pickles → `torch.load(..., weights_only=False)`. Resume ignores CLI `--overrides`.
- `common_naming_to_robot_body_names` values must be **lists**, not strings.
- `MdpComponent` `static_params` named `threshold`/`weight`/`min_value` are metadata and never reach the compute fn.
- Newton: `TORQUE`/`PROPORTIONAL` wiring is broken (`_update_torques` never called) → use `BUILT_IN_PD` + qfrc injection; marker updates are no-op (draw with viewer `log_lines/log_arrows`).
- Pre-existing F822 errors in `component_factories.py` `__all__` — leave them.
- Tracker observations use a 50 ms step. Run 10 ms assistance through `SubstepHookMixin`; the hook simulator disables CUDA graphs.
- Suit bone meshes are visual only; headless Newton skips them. Check `parse_visuals` if large-batch simulation becomes unexpectedly slow.
- Compare torque squared, forward speed, tracking, falls and other joints together. Torque squared is a simulation burden metric, not measured muscle activity or metabolism. Report comparison values directly or in absolute units; do not replace them with percentage-point shorthand.
- Research-side pitfalls (RNG pairing, fps, zarr versions): framework doc §8.

## Code Standards

- Pre-commit: Ruff lint/format, `typos`, Apache-2.0 header on every `.py` except setup.py — copy the header **verbatim** from an existing file (e.g. `protomotions/maniflow/angle_estimator.py`); no abbreviated form.
- Commits: `git commit -s` (DCO); gitmoji prefix + English subject.
- OOP (`nn.Module` subclasses) for model architectures; functional style for data pipelines.
