# 2026-10-13 정리 전 문서 보관본

이 폴더는 당시 문서의 원문이다. **현재 지시·현재 상태로 사용하지 않는다.**
“학습 중”, “일시정지”, “다음 작업”, GPU 오류 등은 과거 시점의 기록이다.
현재 상태는 [HANDOFF](../../HANDOFF.md), 실험 결론은 [실험 결과 요약](../../experiment_summary.html)에서 확인한다.

- [실험 일지 원문](NEXT_SESSION.md): §2–§2-AA 등 기존 인용 근거.
- [기존 HANDOFF](HANDOFF.md): 중복된 세션별 인계 기록.
- [기존 버전표](AI_SBC_VERSIONS.md): 이전 모델 계보.
- [기존 프레임워크](AI_SBC_FRAMEWORK.md): 제거한 초기 실험·정리 이력.

- [통합 실행 README 원문](assist_skeleton_README.md): 초기 전신 보조 실험 일지. 원래 위치 `examples/experiments/assist_skeleton/README.md`.
- [ManiFlow README 원문](maniflow_README.md): 이전 토크 직접 예측과 H0 연결 설명. 원래 위치 `protomotions/maniflow/README.md`.
- [L1 모델 기록 원문](L1_INFO.md), [W1 모델 기록 원문](W1_INFO.md): 학습·선정 근거와 초기 비교표. 원래 위치 각 `checkpoints/<모델>/INFO.md`.

원문 바이트를 보존했으므로 원문 안의 상대 경로는 이전 위치를 기준으로 읽는다.
별도 표기하지 않은 원문의 이전 위치는 `docs/`다.
실험 가중치, 데이터, 로그를 이 폴더로 옮기거나 삭제하지 않았다.
