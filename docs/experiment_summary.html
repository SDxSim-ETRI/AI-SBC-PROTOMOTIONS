70–90%는 참조 고관절의 최대 굴곡을 0%로 잡은 한 주기 안의 구간이다. 발 접촉으로 정한 구간이 아니다. 토크 크기는 제곱 평균의 제곱근(RMS)이며, 양수면 보조 후 착용자 부담이 더 커진 것이다. 학습 1회는 256개 보조 환경×32제어단계=8,192표본을 수집하는 반복이다.

기본 걷기의 개선은 확인됐다. 같은 저장 모델을 다른 난수 초기값과 시작 구간으로 평가해도 고관절 부담은 약 66–69% 줄었다. 새 사람이나 다양한 실제 걷기에서 검증했다는 뜻은 아니다.

느린 조건과 다른 관절은 해결되지 않았다. 같은 동작을 0.90배로 재생하면 문제 구간의 착용자 토크가 9.71–10.87 N·m 늘었다. 기본 걷기에서도 허리 부담은 34.27%, 무릎은 5.22% 늘었다. 고관절의 약 69% 감소를 전신 에너지 감소로 말할 수 없다.

왜 실제 보행 자료를 따로 확인했나

재생 속도만 낮추면 같은 보폭·자세 경로를 천천히 따라가게 된다. 실제 사람이 느리게 걸 때 바뀌는 보폭·관절 움직임을 모두 반영하지는 못한다. 따라서 원래 느림·보통으로 촬영한 자료를 찾았다. 원본과 suit의 골격이 달라 전신 자세를 변환한 뒤, 보조를 끄고 추종부터 확인했다.

“참조 표현”은 착용자에게 따라가라고 주는 몸체 위치·회전·속도 배열이다. 기존 파일은 이 배열과 관절각으로 계산한 자세가 일치하지 않는다. 이를 일치하도록 바꾸자 기존 걷기에서도 낙상했다. 초기 관측 이력도 함께 바뀌는 실험이다. 이것이 새 보행 실패의 유일한 원인이라고 확정한 것은 아니며, 발 접촉·지지 높이 문제도 남아 있다.

시작 시각은 원본 0초와 0.75초다. 조건마다 같은 초기 상태의 복제 환경 두 개를 사용했으며 독립 사람이 아니다. 짧은 원본 끝에서 종료하므로 평가 길이가 다르다. 모든 자료는 같은 suit 체형과 같은 가상 착용자로 실행했다. 후보의 원본은 각도 예측기 원본 자료 목록과 겹치므로 시스템 전체 미사용 자료라고 부르지 않는다.

A443 같은 번호는 무엇인가?

원본 데이터에서 촬영한 사람을 구분하는 코드다. BONES-SEED 메타데이터의 actor_uid 값을 그대로 가져왔다. 제가 실험 종류를 나누려고 붙인 번호가 아니며, 큰 숫자가 빠른 속도나 좋은 모델을 뜻하지 않는다.

보통·느림 자료는 A443–A446의 각 2클립이고, 빠른 후보는 A005·A006·A417이다. 같은 사람의 보통/느림을 짝지어 보려는 구분이었다. 빠른 후보는 사람이 달라 속도만의 효과로 비교할 수 없다. 앞으로 요약 본문은 동작과 인원수로 설명하고, 원본 코드는 재현용 상세표에 남긴다.

또한 “무보조 A / 보조 B”의 A는 동작 수행자 코드와 무관하다. 보조를 끈 비교 조건이라는 뜻이다.

새 보행 변환·무보조 평가 상세 근거 · 원본 보행 자료 점검

다음 할 일은 하나다

새 실제 보행을 보조 없이 안정적으로 추종할 수 있게 한다. 기존 데이터 생성 규약과 착용자 입력을 맞추고, 새 자료의 발 접촉·높이를 보완한다. 기존 착용자가 계속 실패하면 좌표가 일치하는 자료로 별도 착용자를 학습할 필요가 있다.

그 조건이 마련된 뒤 보조 전후의 고관절·허리·무릎 부담과 동작 유지 여부를 비교한다. 지금 같은 보조 학습을 더 오래 돌리거나 달리기로 넓히면, 착용자 실패와 보조 제어 실패가 다시 섞인다.
