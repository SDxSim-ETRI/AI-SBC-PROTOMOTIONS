# 진자 사전학습 개선 최종안

> 현재 실행은 [HANDOFF](HANDOFF.md)의 G0–G4 무작위 초기화·±23 N·m 조건을 따른다. 아래 20 N·m·G0/PA 관련 계획은 이전 설계·결과의 배경이다. L1 기준은 ×0.5를 유지한다.

2026-10-14 사용자 범위 확인 반영. **현재 최우선 작업은 진자 환경에서 학습하는 보조 정책(LLP)의 성능을 최대한 높이는 것이다.**
[HANDOFF](HANDOFF.md)도 이 순서로 변경한다. 새 실제 보행의 무보조 추종 확보는 후순위로 옮긴다.
아래는 구현·실험 설계이며, 완료된 첫 비교·후속 결과와 현재 실행은 §10 및 [HTML 리포트](pendulum_research_report.html)에 반영한다.

**결과 해석 범위(2026-10-15):** 기존 L1과 현재 C0는 학습 한계뿐 아니라 사람 PD+FF 및 외부 주입 토크 처리도 다르다.
현재 표는 공통 평가 환경에서 저장 정책의 성능을 비교한 것이다. “40 N·m 학습 후 ×0.5가 20 N·m 직접 학습보다 낫다”는 인과 결론은 없다.
이를 확인할 기존/수정 토크 처리 × 학습 한계 20/40의 대조 실험 결과는 아직 없다.
각 4,096환경·6,000 epoch·seed 0/1·무작위 초기화·고정 마지막 epoch·평가 적용 20 N·m로 비교한다.
계획과 저장 설정 검사: `results/pendulum_limit_control_20261015/`. L1에서 출발하는 PA_E/PA_H1은 이 비교를 대신하지 않는다.

## 1. 목표와 학습 범위

**고정 골반의 좌우 진자 환경에서, 목표 운동을 유지하면서 사람 역할 제어기의 부담을 최대한 줄이는 LLP를 학습한다.**
진자 물리 자체를 신경망으로 학습하는 것이 아니라, 진자 환경 안에서 보조 토크를 내는 정책을 학습한다.

- 학습 환경은 기존 hip_pendulum이다. 사람 역할은 PD와 속도 feedforward가 맡고, LLP는 추가 보조 토크를 낸다.
- 의도 궤적은 합성 운동으로 만든다. 주파수·진폭·정지·전환과 관성·하중·사람 제어기 조건을 다양하게 준다.
- P1의 외부 토크는 **진자 관절에 주입하는 외란**이다. 보조 모터 출력이나 학습시킬 정답 토크가 아니다.
- 외란을 특정 W1 보행 위상의 토크 표에 맞추거나, 착지·이지 시각을 재현하도록 학습 환경을 고정하지 않는다.
- 이번 작업에 전신 보행 rollout을 이용한 LLP 학습이나 W1 재학습은 포함하지 않는다.
- 기존 W1 걷기·달리기는 진자에서 학습한 정책의 전이 평가에 쓴다. 전이 결과는 진단 근거로 활용하되,
  W1 한 클립의 토크 곡선을 정답으로 삼거나 그 점수만으로 진자 설계를 선택하지 않는다.
- 전신 추가학습은 별도 후속 단계다. 진자 실험이 한 번 실패했다는 이유로 자동 전환하지 않는다.

이전 안의 “보행 연동 외란”, W1 토크 분포 일치 검사, W1의 50 ms 목표 갱신 모사는 이 범위에 맞게 수정했다.
**진자 내 학습 성능과 학습에 쓰지 않은 진자 조건의 보조 성능을 우선 확인하고, 전이 성능을 별도로 보고한다.**

## 2. 고정할 제약

- 실행 센서: 좌우 hip 관절각, 몸통 IMU pitch·roll. 힘·토크·발 접촉은 정책 실행 입력에 넣지 않는다.
- 새 정책: 각 관절 적용 토크 ±20 N·m, 배율 1, LLP 주기 10 ms. L1 ×0.5는 역사적 비교 기준으로 남긴다.
- 수동 보행 위상 게이트는 사용하지 않는다. 진자 외란 발생 조건을 정책 출력 차단 규칙으로 옮기지 않는다.
- 합성 운동과 랜덤 하중을 충분히 유지한다. 보조가 필요 없는 가벼운 환경만 만들어 점수를 높이지 않는다.
- 진자에서의 정지·운동 시작/종료도 검사한다. 이를 실제 사람의 정지·계단·경사 보조 검증이라고 부르지 않는다.
- 무보조 추종에 실패한 새 보행은 LLP 성능 판정에 쓰지 않는다. 그 자료의 정비가 진자 실험의 선행 조건은 아니다.

토크 제곱 평균은 시뮬레이션의 부담 지표이며 실제 근활성이나 대사량을 측정한 값이 아니다.

## 3. 초안에서 바로잡은 판단

| 초안의 주장 | 검토 후 판단 |
|---|---|
| L1의 출력을 20으로 자르면 기존 ×0.5와 같다 | 다르다. L1 출력이 40·tanh(a)일 때 ×0.5는 20·tanh(a), 자르기는 clip(40·tanh(a), ±20)다. 예를 들어 원출력 10 N·m는 각각 5와 10 N·m가 된다. |
| β=1의 −28.1%가 20 N·m 성능 천장이다 | **특권 피드백 기준값**이다. 구현은 보조를 받고 있는 착용자의 직전 10 ms 창 PD 토크를 사용한다. 최적 제어도, 무보조 정답도 아니다. L13R의 약 −30.3%가 이미 이를 넘는다. |
| 격차는 두 전환 구간에서 생긴다 | L1의 직접 손해는 주로 68–92%다. 20–40%는 L1에서는 약한 이득이며, L8에서 큰 손해다. 이후 전이 평가에서 이 구간들을 확인한다. |
| 진자에는 사람 토크 없이 움직이는 구간이 없다 | 중력이 있고 L3~L5에는 외부 감속도 이미 있다. 문제는 **보행의 다관절 결합에 따른 운동학–필요 토크 관계를 충분히 재현하지 못한 것**이다. |
| 각도만으로 전환·필요 토크를 식별할 수 있다 | 특정 주기 보행에서 상관을 배울 수 있다. 같은 관측 이력에도 하중·근력·무릎 상태가 다를 수 있으므로 토크가 유일하게 정해지지는 않는다. |
| HLP가 50 ms 전에 착지를 알려 준다 | H1은 현재~50 ms를 예측하지만 현재 L1 계열 LLP 입력은 0/10/20 ms 세 점이다. 굴곡 정점은 분석 위상 0의 정의이며, 실제 접촉과의 일치는 별도 검증 대상이다. |
| 몸통 pitch로 hip의 수직 통과를 보정하면 된다 | 몸통 IMU와 골반 자세는 동일하지 않다. 현재 pitch·roll은 HLP에 들어가며 LLP actor의 직접 입력도 아니다. 보정식을 전제로 삼지 않는다. |
| 주기 0.7–1.4 s로 다양성을 확장한다 | 현재 0.4–2.0 Hz는 주기 0.5–2.5 s다. 제안 범위만 쓰면 오히려 좁아진다. |
| 플랜트 무보조 파형이 맞으면 학습·전이는 따라온다 | 필요한 검사지만 충분하지 않다. 보조 입력에 대한 응답, HLP 오차, 폐루프 안정성과 실제 전이를 추가로 확인해야 한다. |

유각 원인 해석도 범위를 지킨다. 전신 계측은 무릎·골반 결합 등이 hip 자체 관성항과 상쇄됨을 보여 준다.
이는 같은 궤적의 운동방정식 항 분해다. 무릎을 독립 조작한 인과 실험이나,
LLP가 내부적으로 “감속=사람 제동”이라는 규칙을 쓴다는 증명은 아니다.

아래는 기존 기록을 새 시뮬레이션 없이 재집계한 값이다. W1, 기존 걷기 motion 0, 40 s, seed 42.

## 5. P1: 진자에 가하는 외란을 개선한다

외란은 진자를 외부에서 밀거나 잡아당기는 토크다. 사람 역할 제어기가 내는 τ_h,
보조 모터가 내는 τ_a, 외란 τ_ext를 분리한다. 예를 들어 외부 감쇠가 진자를 감속시키면,
그 감속에 필요한 토크 전부를 사람 역할 제어기가 내지 않아도 된다.

~~~text
I_eff * θ̈ = τ_h + τ_a + τ_g + τ_passive + τ_ext
τ_ext = w_load * clip(k * (θ - θ_0) + b, ±L)
        - w_damp * c * θ̇ + τ_pulse
~~~

θ는 실제 진자 각도, τ_g는 중력, τ_passive는 기존 관절 마찰 등이다.
중력·기존 마찰은 시뮬레이터에 이미 있으므로 외란에 다시 더하지 않는다.
w_load, w_damp는 외란이 나타났다 사라지는 매끄러운 창이다.

초기 비교는 **에피소드 단위로 운동 상태와 관계있는 외란 50% / 기존 시간 랜덤 외란 50%**로 시작한다.
50%는 실험 시작값이며 최적값이라는 주장은 아니다.

| 외란 | 바꾸려는 점 | 조건 |
|---|---|---|
| 각도 의존 하중 | 같은 방향으로 움직여도 필요한 사람 토크가 변하거나 반전하는 조건을 만든다. | θ_0·k·b·L을 진자의 운동 범위와 안정성에 따라 샘플링한다. W1의 반전 각도에 맞추지 않는다. |
| 외부 감쇠 | 감속이 사람 제어기 때문인 경우와 외부 감쇠 때문인 경우를 함께 경험하게 한다. | 방향·시점·길이·크기를 다양하게 준다. 특정 다리의 유각이나 반대쪽 입각과 결부하지 않는다. |
| 펄스·지속 하중 | 큰 힘을 대신 내야 하는 상황을 보존한다. | 기존 랜덤 외란을 대조군으로 유지한다. 큰 하중을 항상 중복해서 더하지 않는다. |

- 각도 의존 항은 +k(θ−θ_0)일 때 각도 이탈을 키울 수 있다. 수동 복원 스프링으로 부르지 않고,
  부호·토크 한계·유효 강성과 무보조 안정성을 확인한다.
- 외란 창은 랜덤 시간 또는 해당 진자의 운동 사건(각도 통과·가속/감속·반전)으로 만든다.
  두 운동 방향 모두 포함하며, 외란 파라미터는 에피소드/사건 경계에서 정한다.
- 감쇠 사건의 25%에서는 c=0, 나머지는 U(0,c_max]로 시작한다.
  연속분포에 0을 포함하는 것만으로 감쇠 없는 사건이 생기지는 않으므로 별도 확률을 둔다.
  25%는 임시값이고 필요하면 0/50%와 비교한다.
- c_max는 기존 관성·각속도에서 약한 감쇠부터 사람 제어기 부담을 상당히 대신하는 감쇠까지 포함하도록 정한다.
  환경이 항상 목표 운동을 대신 만들어 보조 학습 신호를 없애지 않게 한다.
- 하중을 낮춰서 평균 보상이 좋아진 것과 같은 하중에서 정책이 좋아진 것을 구별한다.
  최종 정책 비교는 동일하게 고정한 진자 평가 조건에서 한다.
- actor에는 외란 종류·계수·발생 예정 시각을 알려주지 않는다. 운동학만으로 힘의 원인이 구별되지 않는 경우도 기록한다.

기존 L3~L5도 외부 감속을 사용했다. 따라서 감속 항을 다시 켠 것만으로 개선안이라고 하지 않는다.
새 가설은 **부담이 필요한 조건을 보존하면서 외란의 운동 의존성과 크기·시점을 넓히는 것**이며,
기존 랜덤 외란과 직접 비교해 효과를 확인한다.

현재 관성 ×1–25는 질량중심 관성 배율이다. 질량 고정 설정에서 hip 축 유효 관성은 약 0.42–3.58 kg·m²다.
우선 이 범위와 기존 사람 게인·속도 feedforward를 보존해 외란 변경의 효과를 분리한다.

## 6. 관측·출력·사람 모델·보상

### P0. HLP 관측이 학습과 실행에서 같은 의미인지 확인한다

현재 LLP는 좌우 상태 이력, HLP 미래 hip 각도, 이전 명령 이력을 받는다.
H1은 hip 두 채널과 몸통 pitch·roll을 받고, LLP에는 예측된 hip 각도를 전달한다.

- 첫 대조군은 기존 250 ms 상태 이력과 0/10/20 ms 미래 창을 유지한다.
  0~50 ms 전체 사용이나 IMU 직접 입력은 필요할 때 별도 실험으로 비교한다.
- 에뮬레이터가 합성 의도 θ_g의 미래를 주는 것과, H1이 실제 각도 θ의 이력으로 예측하는 것은 다르다.
  외란이 클 때 학습에만 있는 의도–실제 오차가 힘의 힌트가 되는지 진자 rollout에서 확인한다.
- 현재 각도에 정박하는 chunk_anchor=actual도 θ(t)+Δθ_g를 쓰는 근사다.
  L4의 실패를 고려해 이를 단독 해결책으로 채택하지 않는다.
- 실제 H1과 에뮬레이터를 같은 진자 상태 기록으로 비교하고, 작은 배치의 실제 H1 폐루프 평가도 한다.
  고정 골반 진자에 줄 몸통 채널과 영점 조건을 명시한다. W1 토크를 교사로 가져오지 않는다.
- 인과적 각속도 추정, 각도 잡음·영점 오차·지연에 대한 성능도 분리해 확인한다.
  학습에서 쓴 정확한 시뮬레이터 속도를 실기기에서 그대로 측정할 수 있다고 가정하지 않는다.

### P2. 20 N·m와 구동기 응답을 일치시킨다

새 정책은 20·tanh(a)를 요청한다. 구동기 응답을 모델링할 때는 진자 학습과 전신 평가에서 같은 함수를 쓴다.

~~~text
u_k = 20 * tanh(a_k)
v_k = τ_(k-1) + α * (u_k - τ_(k-1))
α = Δt / (Δt + 1/(2π f_c))
τ_k = clip(τ_(k-1) + clip(v_k - τ_(k-1), ±s_max Δt), ±20)
~~~

Δt=0.01 s다. 저역통과를 끄면 α=1이며, 변화율 제한도 별도로 끌 수 있다.
reset 상태, 요청/적용 토크, 필터·한계 적용 순서를 학습과 추론에서 맞춘다.
보상은 적용 토크로 계산한다. 보조·사람 feedforward·외란의 합에 다른 한계를 다시 적용하는 기존 경로도 확인한다.

20 N·m는 고정 조건이다. **8 Hz / 400 N·m/s는 아직 실측 근거 없는 감도 시험값**이며 기본 하드웨어 사양으로 확정하지 않는다.
먼저 무필터 20 N·m 대조군을 확보하고, 응답 제한을 넣는 실험은 대조군과 후보 모두 같은 조건으로 다시 학습·평가한다.
−20→+20 N·m 전환은 400 N·m/s 제한만으로 최소 100 ms가 걸린다.
스트랩 탄성을 이 필터 하나로 재현했다고 해석하지 않는다.

### P3. 50 ms는 어디에서 왔는가

이전 안의 50 ms는 **W1 착용자 정책의 갱신 주기**에서 가져왔다.
[W1 저장 설정](../../checkpoints/W1_wearer_human/resolved_configs.yaml)의 물리 120 Hz / decimation 6은
6/120=0.05 s이고, [통합 평가](../../examples/experiments/assist_skeleton/run_system.py)는
물리 400 Hz / decimation 20으로 같은 50 ms를 유지한다.

이 값은 사람 반응 시간을 측정한 값이 아니며, 진자 학습을 위해 정한 최적값도 아니다.
H1의 50 ms 예측 길이와도 별개다. 통합 평가에서 물리 적분 한 틱은 2.5 ms이고, 보조 제어는 10 ms다.
사용자 후속 요청에 따라 **사람 역할 제어기의 목표 갱신 간격 10/50 ms를 독립 비교한다.**
50 ms 조건은 PD 목표 위치와 속도 FF의 목표 속도를 갱신 사이에 유지한다.
물리 적분·PD 상태 되먹임·10 ms 보조 제어·HLP 관측 주기를 동시에 바꾸지 않는다.
기존 10 ms 기준군을 먼저 확보하고, 50 ms가 진자 성능에 주는 영향을 평가한다.

### P4. “특권 교사”의 뜻과 이번 결정

시뮬레이터는 실제 장치에서 측정하지 못하는 사람 역할 제어기의 토크 τ_h를 안다.
이 값을 이용해 “보조 토크를 g·τ_h에 가깝게 내라”는 목표를 만드는 것이 이전 안의 “특권 교사”였다.
별도 교사 신경망을 반드시 만든다는 뜻은 아니었다.

| 방식 | 정책에 요구하는 것 | 이번 결정 |
|---|---|---|
| 현재 부담 감소 보상 | 목표 운동을 유지하면서 사람 역할 제어기의 τ_h²·기계적 일을 줄여라. 구체적인 보조 출력은 정책이 찾는다. | 유지 |
| 제안했던 토크 교사 | 보조 출력을 미리 정한 g·τ_h에 맞춰라. | 제외 |
| critic의 추가 정보 | 학습 중 가치 평가에만 외란·사람 파라미터 등을 사용한다. 실행 actor 입력은 센서 범위로 유지한다. | 기존 구조 유지 |

τ_h는 보조가 바꾸는 잔여 토크라서 최적 보조의 고정 정답이 아니다.
단순 모델 τ_h=D−τ_a에서 τ_a=gτ_h를 맞추면 τ_a=gD/(1+g)가 되는 것도 이 때문이다.
“교사가 꼭 필요한 경우”라는 후속 단계도 이번 실행 목록에서 뺀다.
**학습 중 τ_h를 보상 계산에 쓰는 것은 계속하며, 출력 토크를 직접 따라 하게 만드는 추가 교사는 쓰지 않는다.**

### P5. 운동 다양성과 기본 보상

기존 0.4–2.0 Hz, 진폭·중립각·고조파·정지·블렌딩을 우선 유지한다.
추가 다양화는 보행 종류 대신 진자의 주파수 변화, 진폭 변화, 비주기 전환, 하중 변화로 정의한다.

> 2026-10-21 사용자 지시로 이 방침을 바꿨다: 의도 궤적에 실제 보행·주행·앉기류 동작(SEED)을 넣어 학습했다. 결과는 [2026-10-22 보고서](261022_llp20_motion_shared/report.html) — 학습 분포에서는 개선됐지만 실제 H1 예측에서 무너졌다.
빠른·큰 운동이 사람 제어기 한계를 넘는 경우도 구분해 기록한다.

기존 추종 + 사람 역할 제어기의 |τ_h·θ̇| + τ_h² 보상을 기본으로 둔다.
보조 절약항·명령 변화율 비용을 20 N·m라는 이유만으로 없애지 않는다.
각 항의 크기와 clip 빈도를 계측한 뒤 외란 변경과 분리해 조정한다.
L9 반대 방향 비용도 필요할 때 별도 비교하며 처음부터 더하지 않는다.

## 7. 좌우 비대칭과 정책 분리는 다른 선택이다

**좌우 비대칭 학습은 좌우 출력을 일부러 다르게 만들라는 뜻이 아니다.**
두 진자에 다른 진폭·하중·사람 게인을 주어, 한쪽을 보고 반대쪽의 상태를 항상 추정하는 지름길에 의존하지 않게 하려는 것이다.
현재 생성기도 진폭·중립각을 각각 뽑고 일부 조건에서 주파수·위상을 독립적으로 만든다.

현재 actor는 한 신경망으로 두 토크를 출력한다. 두 출력값이 같거나 반대여야 한다는 제약은 없다.
사용자 제안처럼 관절마다 따로 계산할 수도 있다.

| 구조 | 입력과 출력 | 의미 |
|---|---|---|
| 현재 공동 정책 | 양쪽 이력·예측 → 좌우 토크 두 개 | 기존 모델과 비교할 대조군 |
| **공유 단일 관절 정책** | 같은 정책을 오른쪽 입력과 왼쪽 입력에 각각 적용 → 토크 한 개씩 | 동일한 진자 제어 법칙을 양쪽이 공유한다. 우선 비교할 분리 구조 |
| 독립 정책 두 개 | 오른쪽 정책/왼쪽 정책을 각각 학습 | 가능하다. 좌우에 다른 물리·제어 특성이 있어 서로 다른 법칙이 유리한지는 실험으로 판단 |

공유 구조의 계산은 τ_R=π(o_R), τ_L=π(o_L)다. o에는 해당 관절의 상태·예측·명령 이력만 넣고,
부호와 관절 순서는 명시적으로 맞춘다. 같은 가중치를 써도 입력이 다르면 출력은 다르다.
좌우를 서로 다른 학습 분포로 고정하지 않고 같은 조건 분포에서 각각 샘플링한다.

고정 골반·충돌 없는 현재 진자에서 관절별 계산은 자연스러운 비교안이다.
다만 모델을 두 개로 나눈다고 다양한 하중·운동을 학습할 필요가 없어지는 것은 아니다.
관절별 정책이라면 한 관절에서 그 다양성을 충분히 학습하면 된다.

이 변경은 LLP의 입력/출력 형식과 체크포인트 로더에 영향을 주므로 P1 외란 변경과 분리한다.
H1은 여전히 좌우 hip을 함께 보므로, LLP를 관절별로 나눴다고 전체 H1+LLP가 완전히 독립인 것은 아니다.

## 8. 학습 전 진자 검사

처음에는 64 env × 60 s 정도로 점검하되, 같은 파라미터·목표·외란 계획의 무보조/보조 쌍을 만든다.
실제 각도에 의존하는 외란 토크는 두 궤적에서 달라질 수 있으며, 외란 파라미터·사건 계획을 맞춘다.

| 검사 | 확인할 것 |
|---|---|
| 토크 회계 | τ_h, τ_a, τ_ext, 중력·마찰의 분리, 요청/적용값, 같은 시간창 계측, 포화 여부 |
| 무보조 추종 | 운동·하중 범위별 오차·종료·진동. 실패 조건을 조용히 빼지 말고 기록 |
| 외란 강도 | 큰 하중이 남아 있고, 외부 감쇠가 약한/강한/없는 조건이 모두 있는지 |
| 제어 가능성 | 제한된 ±5/±10/±20 N·m 입력에 대한 추종·사람 토크·지연·진동의 반응 |
| HLP 정보 | 의도 에뮬레이터와 실제 H1의 입력 의미·예측 오차·지연 차이 |
| 정책 입력 | 외란·사람 토크·사건 예정 시각이 actor로 새지 않는지 |
| 학습/추론 일치 | 같은 관측·명령에서 토크 한계·필터·reset 결과가 일치하는지 |

W1과 τ_h 부호가 80% 일치해야 한다거나 특정 보행 구간의 감속 비율에 맞아야 한다는 검사는 제거한다.
진자 조건 자체의 안정성·학습 가능성과 다양한 조건에서의 성능을 확인한다.

## 9. 실행 순서와 선택 기준

### 실험 순서

| 순서 | 실험 | 직접 비교 |
|---|---|---|
| 0 | 진자 토크·HLP·관측·출력 경로 점검 및 평가 조건 고정 | 현재 구현에서 실제로 적용되는 조건 확인 |
| C0 | L1/v4 기본 레시피, 새 정책 한계 20·배율 1 | 새 진자 학습 기준군 |
| S1 | C0 + P1 운동 의존 외란 혼합 | 외란만 바꾼 효과 |
| A1 | C0 + 공유 단일 관절 정책 | 공동 actor와 관절별 actor의 차이 |
| T1 | C0 + 사람 PD/FF 목표를 50 ms마다 갱신 | 기존 10 ms 목표 갱신과의 차이 |
| S2 | 개선이 확인된 외란 + 개선이 확인된 정책 구조 | 두 변경을 합쳐도 효과가 유지되는지 |
| 후속 | HLP 에뮬레이션, 구동기 응답, 사람 게인·보상·의도 범위 | 진단에 근거해 한 축씩 변경 |

P0에서 관측 계약 오류가 발견되면 공통 수정부터 하고 C0/S1/A1에 동일하게 적용한다.
물리 한계 20 N·m는 모든 새 실험에 적용한다. 임시 구동기 응답값을 쓸 때도 대조군과 후보를 같은 조건으로 비교한다.
두 독립 정책은 공유 단일 관절 정책과 비교할 이유가 확인된 뒤 추가한다.

- 신규 실행은 새 config로 시작한다. resume은 기존 pickle을 읽으므로 CLI 변경만으로 조건이 바뀌었다고 보지 않는다.
- 직접 대조군과 후보는 같은 학습 seed·수집 step 예산으로 비교한다. 후보 확인에는 최소 두 학습 seed를 사용한다.
- 초기 탐색은 2,000 epoch, 유망한 직접 대조군과 후보는 6,000 epoch까지 같은 예산으로 비교한다.
  이는 첫 비교 예산이며 진자 개선 자체의 영구 상한은 아니다. 1,000 epoch마다 미사용 진자 조건에서 평가한다.
- 명백한 수치 오류·추종 붕괴는 중단한다. 단 두 번의 평균 개선 부재만으로 자동 종료하지 않는다.
- 실패하면 해당 진자 가설을 진단하고 다음 수정 근거를 남긴다. W1 맞춤 플랜트나 전신 학습으로 자동 전환하지 않는다.

### 1차 선택: 진자 조건에서의 보조 성능

학습 seed와 별개인 고정 평가 seed·의도·외란 계획을 두고, 관성·하중·사람 게인의 미사용 조합을 포함한다.
checkpoint 선택에 사용하는 검증 세트와 최종 확인 세트를 구분한다.
HLP·의도·외란의 난수 흐름과 lazy init을 확인해 조건별 RNG가 어긋나지 않게 한다.

우선 무보조 대비 추종·안정성을 유지하는 후보를 고르고, 같은 평가 조건에서 사람 토크 제곱 평균과
|τ_h·θ̇|가 얼마나 줄었는지 비교한다. 전체 평균과 함께 고하중/저하중, 외부 감쇠 유무, 운동/정지/전환,
관성·게인별 결과를 낸다. 한 관절의 이득이 다른 관절의 손해를 감추지 않게 개별 집계한다.

무보조보다 덜 움직여 부담을 낮추는 해, 환경이 목표 운동을 대신해서 보조가 불필요해진 해를 성공으로 보지 않는다.
같은 평가 분포의 C0보다 개선되는지 확인하고, 적용 보조 RMS·포화율·변화율도 함께 기록한다.
추종 허용 오차는 C0/무보조 반복 산포를 확인한 뒤 후보 비교 전에 고정한다.

### 2차 확인: 기존 W1에서 전이가 유지되는지

진자에서 선택한 정책을 고정하고 기존 W1 걷기·달리기에서 40 s 비교한다.
기존 seed 42·7은 개발 이력이 있으므로 독립 최종 검증이라고 부르지 않는다.
전이 성능이 나쁘면 그 한계를 보고하고, 진자 내 성능 향상과 실사용 관련 개선을 구별한다.

- 같은 구동기 조건의 L1과 비교한다. β 기준도 필터 적용 경로를 맞춘다.
  현재 β는 controller 출력 뒤에 토크를 덮어써 기존 필터 옵션만으로는 같은 처리가 되지 않는다.
- 전체·구간 지표의 시간창을 통일한다. 낙상한 짧은 구간의 평균을 성공으로 쓰지 않는다.
- 참조 굴곡 정점=0인 위상에서 좌우 각각 25개 bin의 RMS 변화를 보고, 표본 수와 주기 단위 재표집 산포를 낸다.
- hip 부담뿐 아니라 전진 속도·몸체 추종·낙상·무릎/허리/발목 부담을 함께 확인한다.
- 걷기 −26%, 모든 4% bin RMS 증가 ≤2 N·m, 달리기 −30%는 전이 도전 목표다.
  이 수치를 맞추기 위해 W1 토크를 진자 정답으로 넣지 않는다.
- 실제 속도별 보행·다른 착용자 검증은 후속 과제다. 새 자료의 무보조 추종 실패는 진자 학습을 막는 선행 장애가 아니다.

## 10. 현재 다음 작업과 산출물

**첫 4개 모델의 각 2,000 epoch 학습과 24건 평가를 완료했다(2026-10-15 01:46 KST).**
새 모델은 아직 L1을 대체하지 못했다. 아래 토크 경로 수정을 공통 적용한 결과다. C0 연장·공유 정책 포화 진단·실제 H1 폐루프 검사도 완료했으며, 현재는 L1에서 시작하는 진자 추가학습 PA_E/PA_H1을 비교한다.
기존 C0/A1/C0c는 진단용으로 중단하고 원본을 보존했다.
합산 주입 토크에 착용자 한계를 재적용하던 경로는 16 환경·200 step에서 최대 120 N·m 차이를 만들었다.
그 제한만 제거하면 사람 PD와 FF의 별도 포화 때문에 불안정성이 드러났다.
따라서 새 공통 조건은 다음과 같다.

~~~text
사람 토크 = clip(Kp * (θ_g - θ) + Kd * (v_g - θdot), ±150 N·m)
외부 주입 = 보조 토크(±20 N·m) + 외란
~~~

Newton의 위치 PD 입력을 `θ_g + Kd/Kp * v_g`로 이동시켜 위 식을 같은 actuator 안에서 계산한다.
이는 목표 동작 θ_g 자체를 바꾸는 것이 아니라 속도 보상 항을 하나의 토크 제한 안에 넣는 대수적 변환이다.
양의 Kp를 요구하며, FF는 외부 주입이나 사람 토크 계측에 다시 더하지 않는다.
기존 모델·레시피는 `human_feedforward_inside_pd=False`를 유지하고 새 비교군에만 켠다.

동일한 목표·관성·기본 게인의 256 에피소드(각 10초)에서 별도 FF 포화와 전체 사람 토크 포화를 비교했다.
무보조 실패는 192→5회, 기존 L1×0.5의 보조 실패는 162→0회였고, 주입 차이는 0이었다.
실제 사람/보조 최대 토크도 150/20 N·m였다. 이는 환경 검증이며 새 정책 성능 향상으로 세지 않는다.

- A1은 약 98%의 관절 표본에서 |보조|>19 N·m였다. 입력 분해·좌우 독립성·가중치 로드는 검사했지만 이 현상의 원인이 구조 자체라고 확정하지 않는다.

### 실제 H1 폐루프 진자 평가

고정 H1(denoise 1, 몸통 pitch/roll 0, 10 ms 갱신)을 actor에 연결했다.
8환경×100step 무보조 검사에서 H1 유무에 따른 목표·관성·게인·외란·관절 궤적이 bitwise 동일했고,

그 정보 차이와 예측 오차를 이번 교체 실험만으로 분리할 수는 없다.
오프라인 각도 예측 오차가 더 작다는 사실이 보조 성능 개선을 보장하지 않았으므로,

현재 P0의 예측 정보 차이를 직접 비교한다. 기존 L1 actor에서 시작해 PA_E는 합성 예측, PA_H1은 동결 H1의 실제 예측으로 **진자에서만** 추가학습한다. 두 조건 모두 512환경·2,000 epoch·actor LR 3e-5·critic/optimizer 새 초기화이며 보조는 처음부터 20*tanh(action)이다. H1은 진자 각도 이력과 몸통 0만 받아 예측하며 목표 의도·외란은 입력받지 않는다. 별도 토크 교사는 없다.

H1 생성/추론 RNG를 분리하고 기존 합성 예측 난수 소비를 유지한다. GPU 예비검사에서 무보조 물리·목표·외란 RNG 동일, 학습/평가 H1 예측 최대 차이 1.53e-7 rad, 부분 reset 이력 분리, 초기 L1 actor 출력 동일, 3 epoch 학습을 확인했다. 각 100/300/600/1,000/2,000 epoch를 기존 평가로 비교하고 통과 후보만 추가학습 seed 1 및 별도 평가 seed로 검증한다. L1 사전학습 seed는 공통이므로 추가학습 재현성으로만 해석한다.
