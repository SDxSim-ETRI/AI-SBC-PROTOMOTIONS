원본 데이터에서 촬영한 사람을 구분하는 코드다. BONES-SEED 메타데이터의 actor_uid 값을 그대로 가져왔다. 제가 실험 종류를 나누려고 붙인 번호가 아니며, 큰 숫자가 빠른 속도나 좋은 모델을 뜻하지 않는다.

보통·느림 자료는 A443–A446의 각 2클립이고, 빠른 후보는 A005·A006·A417이다. 같은 사람의 보통/느림을 짝지어 보려는 구분이었다. 빠른 후보는 사람이 달라 속도만의 효과로 비교할 수 없다. 앞으로 요약 본문은 동작과 인원수로 설명하고, 원본 코드는 재현용 상세표에 남긴다.

또한 “무보조 A / 보조 B”의 A는 동작 수행자 코드와 무관하다. 보조를 끈 비교 조건이라는 뜻이다.
